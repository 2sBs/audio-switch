How Audio Switch works

01 / Set up once

Assign device roles

Pick Primary and Secondary microphones, your virtual cable, and optional playback devices.

02 / Control locally

Switch from wherever you work

Use the Windows tray or Mac menu bar, press your shortcut, or install the optional Stream Deck plugin for either platform.

03 / Stay connected

Apps use one stable input

Games, calls, and recording tools keep the same selected device while the physical source changes.

Guided setup

Install it.
Set the route.
Leave apps alone.

Windows
Windows 10 version 1809 or newer, including Windows 11. x64.
macOS
macOS 14.2 or newer on Apple silicon. Intel Macs are not supported.
Stream Deck Optional
Stream Deck 7.1 or newer. Keep Audio Switch running to use the plugin.
  1. 01

    Install a virtual audio cable from its publisher: VB-CABLE for Windows or BlackHole for macOS. Audio Switch does not include a driver.

  2. 02

    On Windows, run the installer. On macOS, unzip the app and move it to Applications. Open Audio Switch, allow audio access, and choose both physical microphones.

  3. 03

    Select the virtual cable as the microphone in your apps: CABLE Output on Windows or BlackHole on macOS. Leave that input selected when you switch physical microphones.

  4. 04

    Switch physical sources without revisiting app settings. The selected microphone opens when an app records from the virtual cable and is released when recording stops.

Playback

Mirror a second output

Copy audio from your Primary playback device to Secondary. Mirroring pauses when a device disconnects or your system plays through another output.

Local by design

No account or telemetry

Audio routing and settings stay on your computer. There is no hosted service behind the app.

Before you open it

The Windows installer is unsigned, so SmartScreen may warn. The Mac app is not notarized; if macOS blocks it, choose Open Anyway in System Settings → Privacy & Security.

Compare your download with the release’s SHA-256 checksum. Mac updates are manual and may require audio permissions again.
