How Audio Switch works

01 / Set up once

Assign device roles

Pick Primary and Secondary microphones, your virtual cable, and optional playback devices.

02 / Control locally

Tray, hotkey, or Stream Deck

Switch from the taskbar, press Ctrl + Shift + F11, or install the optional Stream Deck plugin.

03 / Stay connected

Apps use one stable input

Games, calls, and recording tools keep the same selected device while the physical source changes.

Guided setup

Install it.
Set the route.
Leave apps alone.

  1. 01

    Install a virtual audio cable such as VB-CABLE from its publisher.

  2. 02

    Run Audio Switch and choose both physical microphones.

  3. 03

    Select the virtual cable as the microphone in your apps.

  4. 04

    Switch physical sources without revisiting app settings.

Playback

Mirror a second output

Send audio from your Primary playback device to Secondary while both endpoints are available.

Local by design

No account or telemetry

Audio routing and settings stay on your PC. There is no hosted service behind the app.
